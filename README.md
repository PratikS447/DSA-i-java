## 🧠 Topics Covered

| Category | Topics |
|---|---|
| **Arrays** | 1D/2D arrays, sliding window, two pointers |
| **Strings** | Pattern matching, string manipulation |
| **Linked Lists** | Singly, doubly, circular linked lists |
| **Stacks & Queues** | Implementation, applications |
| **Trees** | Binary trees, BST, traversals |
| **Graphs** | BFS, DFS, shortest path |
| **Recursion & Backtracking** | Subset generation, N-Queens, etc. |
| **Sorting** | Bubble, Merge, Quick, Heap sort |
| **Searching** | Linear, Binary search |
| **Dynamic Programming** | Memoization, tabulation, classic problems |

## 🚀 Getting Started

### Prerequisites

- Java 11 or higher
- Maven

### Clone & Run

```bash
git clone https://github.com/PratikS447/DSA-i-java.git
cd DSA-i-java
```

Open in your preferred IDE (IntelliJ IDEA recommended) and run any class with a `main` method directly.

Or build with Maven:

```bash
mvn compile
```
